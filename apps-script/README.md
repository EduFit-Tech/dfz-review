# 의견 받기 켜는 법

페이지의 「의견 보내기」는 구글 Apps Script 웹앱이 받아 구글 시트에 쌓습니다.
조직 구글 계정으로 한 번 배포하면 켜집니다.

## 처음 한 번

1. 조직 구글 계정으로 새 **구글 시트**를 만든다(이름 예: 「디지털 핏 존 리뷰 의견」).
   주소의 `/d/` 와 `/edit` 사이 글자가 시트 ID다. 팀원에게 편집 권한으로 공유한다.
2. 시트에서 **확장 프로그램 → Apps Script**를 연다.
3. `Code.gs`의 내용을 이 폴더의 `Code.gs`로 바꾼다.
4. 왼쪽 **서비스 +** 에서 **Google Sheets API**를 더한다(이름은 `Sheets` 그대로).
5. 왼쪽 **프로젝트 설정 → 스크립트 속성**에 `SHEET_ID` = 1번의 시트 ID를 넣는다.
6. 편집기에서 함수 `authorize`를 한 번 실행하고 권한을 승인한다. 시트에 「의견」 탭이 생긴다.
7. **배포 → 새 배포 → 웹 앱**: 실행 「나」, 액세스 「모든 사용자」. 나온 주소(`…/exec`)를 복사한다.
8. 이 저장소 `data/games.json`의 `requestUrl`에 그 주소를 적고 `python -I tools/build_review.py` 뒤 올린다.

## 의견 공개하기

받은 의견은 **바로 공개되지 않습니다.** 시트의 칸으로 정합니다.

| 칸 | 쓰는 법 |
|---|---|
| 공개 | `공개`라고 적은 줄만 페이지의 항목 아래에 나온다. 비워 두면 건수만 센다. |
| 처리 상태 | `검토 중`·`반영함`처럼 적으면 의견 옆과 항목의 표시에 나온다. |
| 팀의 답 | 적으면 공개된 의견 아래에 「팀의 답」으로 나온다. |

공개하기 전에 볼 것: 실명·연락처·학교와 학생을 알아볼 수 있는 말이 없는지, 광고나 욕설이 아닌지.
시트를 고치면 20초쯤 뒤 페이지에 반영됩니다. 공개를 거두려면 `공개`를 지웁니다.

## 코드를 고쳤을 때

편집기에 붙여 넣은 뒤 **배포 → 배포 관리 → 수정 → 새 버전**. 주소는 그대로입니다.
