G021 반대로 점프! 술래 피하기

화면 속 술래가 속임 동작을 하다가 「점프!」에 맞춰 자세를 잡습니다. 술래와 반대 자세 를 하면 성공! 카메라가 내 자세를 알아봅니다.

의견 받기는 준비 중입니다.

바뀐 기록

  • 2026-11-10 19:47처음 변환 — 참가 → 동작 연습(보정·왼쪽·오른쪽·앉기·만세, 전원 통과, 두 팔 ㄴ자 0.25초면 바로 시작) → 3초 → 경기. 원본 설정 모두(1~2명, 난이도 1~3, 반대로·따라 하기·4문제마다, 박자 셋, 목숨·탈락, 글자 말 속임), 성공 +10·빠르기 보너스, 겨울 학교 놀이터 배경·술래 그림(GPT)

흐름 — 참가 → 동작 연습 → 시작

단계누가무엇
1. 참가 화면앱(그대로)카메라 앞에서 참가 자세 → 모두 준비 자세 → 안내 단계로
2. 입장 뒤 동작 연습이 게임보정(선 위에 바르게 2초) → 왼쪽 → 오른쪽 → 앉기 → 만세 → 시작 자세. 단계마다 참가자 전원이 0.3초 이어야 통과, 모두 통과하면 「잘했어요!」 0.8초 뒤 다음 단계. 어느 단계든 한 명이 두 팔을 ㄴ자로 올리고 0.25초 버티면 연습을 건너뛰고 시작(만세 단계만 예외 — 만세와 헷갈리지 않게). 선생님은 앱의 「바로 시작」/Enter.
3. 게임 시작앱 3초 세기 → 이 게임연습에서 한 보정(선 자리·키)을 그대로 이어 쓴다. 연습을 건너뛰어 보정이 없으면 첫 「가운데로!」에서 바르게 선 자리로 보정

약속은 앱 물풍선 게임의 「동작 익히기」와 같습니다 — 전원 통과, 0.8초 「잘했어요」, 시작 자세 0.25초.

직접 해 보기

C# 판정과 같은 규칙과 숫자로 움직입니다. 「게임 시작」을 누르면 앱처럼 동작 연습부터 합니다. 카메라 대신 키보드로 자세를 냅니다 — 1번: A 왼쪽 · D 오른쪽 · S 앉기 · W 만세 · Q 시작 자세, 2번: ← → ↓ ↑ · / 시작 자세(누르고 있는 동안 그 자세). 아무 키도 안 누르면 「선 위에 바르게 서기」입니다. Enter는 선생님의 「바로 시작」. 2번은 자동 대결자(체험판에만 있는 흉내, 0.25~0.7초 뒤 대개 맞게 움직임)로 둘 수 있습니다.

반대로 점프! 술래 피하기

화면 속 술래가 속임 동작을 하다가 「점프!」에 맞춰 자세를 잡습니다. 술래와 반대 자세를 하면 성공! 카메라가 내 자세를 알아봅니다.

진행 방법
  1. 카메라에서 3m쯤 떨어져 섭니다. 두 명이면 2m 이상 띄워 섭니다.
  2. 동작 연습: 선 위에 바르게 2초 서서 보정하고, 왼쪽·오른쪽·앉기·만세를 한 번씩 해 봅니다. 두 팔을 ㄴ자로 올리면 바로 시작!
  3. 문제마다 먼저 가운데에 바르게 섭니다. 「하나, 둘, 점프!」에 맞춰 술래와 반대 자세 — 왼쪽↔오른쪽, 앉기↔만세.
  4. 성공하면 10점 + 빠를수록 보너스(최대 5점), 틀리면 목숨이 하나 줄고 다 잃으면 탈락합니다.

실물에서 봐 주셨으면 하는 것

  • 좌우 경계 — 원본 「칸 폭 × 5%」를 「화면 폭 ÷ 사람 수 × 5%」로 옮겼습니다. 두 명이면 화면 폭의 2.5%라 꽤 예민합니다. 가만히 서 있어도 왼쪽·오른쪽으로 튀면 경계를 넓혀야 합니다.
  • 시작 자세 — 두 팔을 ㄴ자로 올리기(앱 물풍선과 같은 판정). 연습 중 앉기·만세를 하다가 우연히 시작되지 않는지, 반대로 아이들이 잘 해내는지.
  • 앉기·만세 — 3m 거리에서 무릎·발목이 보이는지(안 보이면 엉덩이 높이만으로 앉기를 봅니다).
  • 흰 눈밭 배경에서 칸·글자가 잘 보이는지(칸 판은 짙은 남색 78%).
